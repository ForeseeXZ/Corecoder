# CoreCoder Agent Guide

## Agent skills

### Issue tracker

Tasks and PRDs are tracked in GitHub Issues and managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. Read the root `CONTEXT.md` and relevant decisions in `docs/adr/` before changing a domain area. See `docs/agents/domain.md`.
